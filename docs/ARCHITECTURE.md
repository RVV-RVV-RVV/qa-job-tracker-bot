# 📘 МАЙСТЕР-ДОКУМЕНТ ПРОЄКТУ: QA Job Tracker Bot
**Версія:** 3.0.4 (Streamlined Flow & Follow-up Manager)
**Стек:** Google Apps Script (GAS) + Telegram Bot API + AppSheet + Gemini AI

---

## 📌 1. РОЛЬ ТА КОНТЕКСТ ДЛЯ ШІ
Ти — персональний AI-асистент та Senior JS/QA Automation Lead. Твоя мета: підтримка, дебаггінг та масштабування автоматизованої системи. **ТИ ЗОБОВ'ЯЗАНИЙ** суворо дотримуватись архітектури та принципів SRP (Single Responsibility Principle).

---

## ⚖️ 2. ГЛОБАЛЬНІ ПРАВИЛА (LAWS OF THE SYSTEM)
1. **Двовладдя (Telegram vs. AppSheet):** - **Telegram** — основний фронтенд для вводу та ШІ-аналізу (State Machine).
   - **AppSheet** — "God Mode". Пряме втручання в БД. Скрипт `autoSortSheet` автоматично виявляє ручні зміни статусів і архівує їх без участі бота.
2. **Human-in-the-loop (Валідація):** Жодна дія ШІ не фіналізується в БД без підтвердження користувачем (`[✅ Так, записуй]`).
3. **Авто-Двірник (Sync Logic):** Реалізовано в `Utils.gs`. При зміні статусу на "Відмова" через AppSheet, система автоматично переносить рядок в Архів, заповнює дату виходу та очищує активну чергу.
4. **Date Blocker:** Система жорстко блокує переходи на етапи "Інтерв'ю" або "Тестове", якщо в звіті ШІ відсутня дата.

---

## 🏗 3. АРХІТЕКТУРА БАЗИ ДАНИХ (Google Sheets)
Система використовує "снайперський запис" для захисту **ARRAYFORMULA** у стовпцях `D` та `F`.

**Стовпці-маркери:**
* **N:** Дата/час інтерв'ю.
* **P:** Лінк на виконане ТЗ (для контролю дедлайнів).
* **R:** Єдиний Cover Letter (затверджений шаблон).
* **S:** Дедлайн здачі ТЗ.
* **U:** Жорсткий дедлайн відповіді (авто-архів після закінчення).

---

## 📂 4. МОДУЛЬНА СТРУКТУРА БЕКЕНДУ (SRP)
1. **`Config.gs`:** Константи, токени, JSON-клавіатури та White-list ID.
2. **`Code.gs`:** Точка входу `doPost`. Сек'юріті-фільтр та первинний роутинг.
3. **`Telegram.gs`:** Низькорівневий сервіс взаємодії з Telegram API.
4. **`AI.gs`:** Промпти Gemini. Генерація Cover Letters, Follow-ups та STLC-аналіз відповідей.
5. **`Utils.gs`:** Ядро автоматизації. Авто-двірник, безпечне сортування за 12+ статусами, валідація дат та парсинг сайтів.
6. **`Logic.gs`:** Бізнес-логіка State Machine.
7. **`Cron.gs`:** Дворівневий детектор гостингу (Фаза 1: нагадування; Фаза 2: авто-архів).
8. **`Data.gs`:** Сховище мотиваційних цитат та статичних промптів.

---

## 🔄 5. СТАТУСНА ВОРОНКА (STLC Funnel)
Система підтримує 12 активних статусів. Пріоритетність при сортуванні:
1. Офер / Переговори.
2. Інтерв'ю / Тестове.
3. Потребує фоллоу-апу.
4. Очікує відповідь.
5. Нова вакансія (Чернетки).
