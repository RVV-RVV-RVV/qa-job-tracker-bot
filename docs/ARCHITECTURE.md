## ⚖️ 2. ГЛОБАЛЬНІ ПРАВИЛА (LAWS OF THE SYSTEM)
* **Двовладдя (Telegram vs. AppSheet):** * **Telegram** — це точка входу первинних даних (текстів). Тут діє жорстка State Machine з обов'язковою валідацією ШІ.
  * **AppSheet** — це "God Mode" (Режим Бога). Пряме втручання в базу даних. Якщо статус змінено через AppSheet, бот не наздоганяє питаннями.
* **Обов'язкова валідація (Human-in-the-loop):** Жоден новий статус через Telegram не записується в таблицю без підтвердження. Бот завжди показує звіт ШІ і питає: `[✅ Так, записуй]` або `[✏️ Виправити]`.
* **Блокувальник подій (Date Blocker):** Система блокує переходи до статусів типу "Інтерв'ю" або "Тестове", якщо дата/дедлайн відсутні. Вимагає ручного введення.
* **Кнопка "❌ Скасувати":** Доступна на будь-якому етапі воронки для миттєвого обнулення State Machine.

## 🏗 3. АРХІТЕКТУРА БАЗИ ДАНИХ (Google Sheets)
Система працює точково ("снайперський запис"), щоб НІКОЛИ не затерти `ARRAYFORMULA` у стовпцях `D` та `F`.

**Ключові стовпці:**
* **A-M:** Стандартні дані (ID, Компанія, Статус, URL, Посада, ЗП, Рекрутер, Канал зв'язку, Нотатки).
* **N:** Дата/час інтерв'ю (Формат: ДД.ММ.РРРР ГГ:ХХ)
* **O:** Посилання на зустріч
* **P:** Виконане ТЗ (посилання/статус)
* **Q:** Сирий текст вакансії
* **R:** Єдиний Cover Letter (затверджений шаблон)
* **S:** Дедлайн ТЗ
* **T:** Аналіз компанії від ШІ
* **U:** Дедлайн відповіді (Дата)

## 📂 4. ФАЙЛОВА СТРУКТУРА БЕКЕНДУ (GAS)
Проєкт розбито на модулі за принципом SRP (Single Responsibility Principle).
1. `Config.gs`: Константи, токени та JSON-клавіатури.
2. `Code.gs`: Точка входу `doPost`. Розпізнавання тексту та callback, перевірка безпеки.
3. `Telegram.gs`: Сервіс відправки повідомлень та редагування меню.
4. `AI.gs`: Інтеграція з Gemini (`responseMimeType: "application/json"`).
5. `Utils.gs`: Допоміжні функції, парсинг, валідація дат, `autoSortSheet`.
6. `Logic.gs`: Ядро (Маршрутизатор). Обробляє State Machine через `CacheService`.
7. `Cron.gs`: Менеджер автономних фонових задач.
8. `Data.gs`: База мотиваційних повідомлень.

## ⏱ 5. ФОНОВІ ЗАДАЧІ (CRON.gs)
* **Рандомна Мотивація:** О 01:00 генерує 2 пуші на випадковий час (Пн-Пт, 09:00-19:59).
* **Невідправлені резюме:** Пн та Чт о 12:00 нагадує про статуси `нова вакансія`.
* **ДЕТЕКТОР ГОСТИНГУ (Дворівневий):** Вт та Пт о 12:00.
  * **Фаза 1:** Якщо статус Відгук/Очікування мовчить `≥ 7 днів` (і немає дедлайну в U) ➡️ Шле список компаній та пропонує надіслати фоллоу-ап.
  * **Фаза 2:** Якщо юзер натиснув "Відправив фоллоу-ап" (у M додається маркер) і минуло `≥ 3 дні` ➡️ Авто-архів зі статусом "Відмова (Загостили)".
* **Жорсткі Дедлайни:** Щодня о 10:00. Якщо Сьогодні `≥` Стовпець U ➡️ Авто-архів ("Відмова по тайм-ауту").
* **Нагадування подій:** Щогодини перевіряє стовпці N (Інтерв'ю) та S (Дедлайни ТЗ). Надсилає пуш за 24г та 1г.
